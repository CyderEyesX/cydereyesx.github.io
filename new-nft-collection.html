Room 08 / 09 · Project Closed

The Wasteland Web

Presearch Node NFTs once represented an active node on the Presearch network and the earning rights that came with it. The Wasteland Web Collection wrapped that utility in narrative: three Web3-native node types — Crawler, Vector, and C-Seek — cast as living artifacts from a rebellion to free knowledge from corporate and alien control, set in the post-algorithmic ruins of the internet.

Curator's note: this project closed unexpectedly, and the infrastructure it promised never arrived. These pieces stay in the archive regardless — not for what they turned out to be worth, but for the art itself, and as a standing reminder that conviction is not due diligence.

Wolfies

5,212 NFTs on Cronos built around a different mechanic: liquidity as a built-in feature. Each Wolfie is backed by $PACK-CRO liquidity pool tokens, redeemable by burning the NFT -- an attempt to address the common "floor price means nothing without buyers" problem in PFP collections.
